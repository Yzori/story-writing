## Core Philosophy
Co-op writing is a writers' room, not a shared document. Collaboration is creative, emotional, and ritualistic — not mechanical.

## 5 Pillars

### 1. Roles, Not Cursors
- ONE person holds "the pen" at a time — the active writer
- Others are Contributors (react, suggest, nudge) or Observers (reading live)
- Feels like: "I'm writing, others are in the room with me"

### 2. Marginal Thinking (Not Comments)
- Highlight text → attach a "thought" (creative impulse, not a comment)
- Appear as soft inline whispers, margin notes, or subtle underlines
- Examples: "Too predictable?" / "What if it's already open?"
- These are creative impulses, not review feedback

### 3. Live Presence (Emotional, Not Technical)
- Don't show cursors/selections/locks
- Show: "Floran is writing..." with words appearing live, slightly faded → solidifying
- Typing rhythm presence: bursts, hesitation dots, edits feel human
- Feels like: watching someone write in a cafe

### 4. Suggestion Layer (Woven Into Text)
- Ghost alternatives appear inline: "She opened the [door]" with "gate" / "rusted entrance" as alternatives
- Click to swap — text is alive with possibilities
- NOT a separate "suggest mode"

### 5. Conversation = First-Class Citizen
- Discussions anchored to specific sentences become mini writers-room threads
- Can "promote" a discussion into the text
- Mark moments as: Turning Point / Conflict idea / Seed for later

## Advanced Ideas
- **Timeline Scrubber** — watch how a scene evolved ("creative archaeology")
- **What If Branching** — fork paragraphs into alternate versions (darker tone, different dialogue)
- **Ambient Mode** — optional typing sounds, page turning, cafe ambience
- **Energy Indicator** — scene active / flow state / stalled (based on typing speed + interactions)
- **Pass the Pen Ritual** — ceremonial handoff with animation: "Flow passes the pen to Elena"

**Why:** This is how real writers collaborate. Not fighting over a cursor.
**How to apply:** Every co-op feature should be evaluated against these pillars. If it feels like Google Docs, rethink it.
